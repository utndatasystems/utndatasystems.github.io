ILIKE Data Skipping

Data Skipping for Expensive Operators.

Project Leads: Mihail Stoian and Andi Zimmerer

Description

ILIKE Data Skipping is a research project by the Data Systems Lab at the University of Technology Nuremberg (UTN) that explores lightweight metadata and indexing techniques for accelerating expensive operators in analytical database systems.

The project studies data skipping for expensive database operations, among them joins and substring searches, at both the row and partition levels. By identifying data that cannot contribute to a query result, database systems can avoid unnecessary scans and expensive computation while preserving exact query results.

“A parrot is much like an approximate membership structure for substrings: give it sentences, and every so often it gives you a few pieces back.”
