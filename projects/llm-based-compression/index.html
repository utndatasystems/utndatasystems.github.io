LLM-Based Compression

Making ML-powered compression fast, robust, and practical for data systems.

Project Leads: Luisa Neubauer and Mihail Stoian

Description

LLM-Based Compression is a research project by the Data Systems Lab at the University of Technology Nuremberg (UTN) that explores two lossless approaches: compressing text with LLM predictions and entropy coding, and using coding agents to create codecs for specific datasets.

We study when storage savings justify compression and decompression costs, how to improve throughput, and how LLM-based compression handles adversarial inputs. Synthesized codecs are verified by reconstructing data byte for byte, then run without model inference while targeting fast decompression and random access.
